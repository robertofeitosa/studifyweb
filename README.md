## Antes de rodar

Leia o arquivo [GUIA_PASSO_A_PASSO.md](GUIA_PASSO_A_PASSO.md).

Para iniciar localmente no Windows, depois de criar o arquivo `.env`, dê dois cliques em:

```text
INICIAR_STUDIFY.bat
```

> Não envie `.env`, senhas ou `OPENAI_API_KEY` ao GitHub.
